# Идеальный год

Веб-сервис для 30-дневного пилота: регистрация по email и паролю, личный маршрут по 12 сферам, одна задача на локальный день, отчёты, история, снимки колеса, добровольная связь Telegram и отдельный кабинет организатора.

## Что уже работает

- Участник создаёт аккаунт, сохраняет код восстановления и входит с серверной сессией.
- В кабинете участник заполняет маршрут, выбирает фокус, получает задачу на свой календарный день и отчитывается о ней.
- Отчёт защищён ключом идемпотентности: повтор запроса не создаёт дубликат.
- Участник скачивает свои данные, может поставить программу на паузу и удалить аккаунт с подтверждением паролем.
- Организатор видит список участников, подключение Telegram, задачи, статусы и агрегированную динамику. Он не видит стартовые ответы, оценки, цели и личные заметки через административный API.
- Участник связывает Telegram сам: сайт создаёт одноразовую deep link-ссылку, бот принимает `/start`, а участник подтверждает связь в кабинете.

Телеграм-бот в этой версии подтверждает связь. Доставка ежедневных задач ботом, групповые чаты, ИИ и платежи ещё не реализованы.

## Локальный запуск

Нужны Node.js 22+ и PostgreSQL 16+.

```bash
npm ci
cp .env.example .env
# укажите DATABASE_URL и APP_ORIGIN в .env
npm run db:migrate
npm run dev
```

Сайт откроется на `http://localhost:3000`. В `.env` для локального запуска укажите:

```dotenv
DATABASE_URL="postgresql://ideal_year:пароль@127.0.0.1:5432/ideal_year"
APP_ORIGIN="http://localhost:3000"
```

После регистрации владельца назначьте его администратором:

```bash
npm run admin:grant -- owner@example.com
```

Команда меняет роль только уже зарегистрированного пользователя. Не используйте её с чужим email.

Для нового публичного развёртывания удобнее задать `OWNER_INVITE_CODE`: тогда при регистрации с этим кодом аккаунт сразу станет кабинетом организатора. Сгенерируйте длинное случайное значение и храните его только в переменных окружения.

## Docker

```bash
docker compose up --build
```

Compose запускает PostgreSQL, применяет миграции и затем стартует приложение. Локальный пароль в `compose.yaml` предназначен только для разработки. Для staging и production используйте отдельную управляемую PostgreSQL и секреты хостинга.

## Telegram

Создайте бота через BotFather, затем добавьте в секреты окружения:

```dotenv
TELEGRAM_BOT_TOKEN="..."
TELEGRAM_BOT_USERNAME="имя_бота_без_@"
TELEGRAM_WEBHOOK_SECRET="минимум-32-случайных-url-safe-символа"
```

После публикации сайта по HTTPS настройте webhook в том же окружении:

```bash
node scripts/telegram-setup.mjs
```

Скрипт сверяет имя бота и устанавливает webhook на `/api/telegram/webhook`. Значения секретов не добавляйте в Git.

## Развёртывание

Для быстрого бесплатного пилота используйте **Vercel** для сайта и **Neon** для PostgreSQL. Репозиторий уже настроен для этого: во время Vercel-сборки запускается `npm run db:migrate`, а миграции безопасно синхронизируются между параллельными сборками.

1. В [Neon](https://console.neon.tech) создайте проект с PostgreSQL и скопируйте connection string. Выберите pooled connection string и не убирайте из него `sslmode=require`.
2. В [Vercel](https://vercel.com/new) войдите через GitHub, импортируйте `dostavkapahon-dev/1` и оставьте предложенные настройки Next.js.
3. В **Project Settings → Environment Variables** добавьте для Production:

   ```dotenv
   DATABASE_URL="connection string из Neon"
   APP_ORIGIN="https://адрес-проекта.vercel.app"
   OWNER_INVITE_CODE="длинный-случайный-секрет"
   ```

   Секрет можно создать локально командой `openssl rand -base64 32`. Не добавляйте его в Git или в переписку.
4. Нажмите Deploy. После успешной публикации зарегистрируйте свой аккаунт, введя `OWNER_INVITE_CODE` в поле «Код организатора». Откройте `/admin`: там появится кабинет организатора.
5. Проверьте `https://адрес-проекта.vercel.app/api/health`. Ответ `{"ok":true}` означает, что сайт и база доступны.

Не задавайте Telegram-переменные, пока бот не создан. Когда сайт получит постоянный HTTPS-адрес, добавьте `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` и `TELEGRAM_WEBHOOK_SECRET`, затем выполните `node scripts/telegram-setup.mjs` в окружении с теми же переменными. До этого сайт остаётся рабочим веб-кабинетом, а Telegram показывает, что бот не подключён.

Перед реальными участниками также опубликуйте реквизиты оператора данных и сроки хранения. На бесплатных тарифах Vercel и Neon есть лимиты, поэтому они подходят для пилота, а не для гарантированной высокой нагрузки.
