# Идеальный год

Первая вертикальная версия веб-кабинета для 30-дневного пилота: 12 сфер жизни, выбор нагрузки для одной задачи дня и личный отчёт. На этом шаге данные хранятся в `localStorage` браузера, чтобы проверить пользовательский путь до подключения сервера.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

Для запуска приложения вместе с PostgreSQL используется Docker:

```bash
docker compose up --build
```

Локальный пароль PostgreSQL из `compose.yaml` предназначен только для разработки. Для staging и production использовать секреты хостинга, отдельную БД и значение `DATABASE_URL` из его secret store.

## Проверки

```bash
npm test
npm run build
```

## Следующий этап

Подключить PostgreSQL, миграции и Google OAuth, затем перенести профиль, оценки, задачи и отчёты с локального состояния на сервер. Для этого потребуются отдельная база данных и Google OAuth credentials. Telegram, ИИ и реальные платежи пока не подключены. Автоматические проверки GitHub Actions запускают тесты и production-сборку на каждом изменении `main` и pull request.

## Правила продукта

Задача «выполнена» сохраняет факт отчёта и не меняет самооценку сферы автоматически. Вопросы, ИИ и будущие материалы не диагностируют, не назначают лечение и не дают религиозных постановлений.
